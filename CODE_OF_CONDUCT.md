# Code of Conduct

## Our standard
This project is a research-engineering collaboration. Participants should communicate respectfully, discuss evidence rather than people, and keep technical disagreements focused on reproducible claims and methods.

Unacceptable behavior includes harassment, threats, discrimination, deliberate disruption, publication of another person's private information, and knowingly submitting fabricated or misleading evidence.

## Scientific integrity
Contributors should cite external sources, preserve provenance, disclose material uncertainty, distinguish observation from inference, and never alter evidence solely to obtain a desired result.

## Reporting
Report conduct concerns privately to the repository maintainer through GitHub. Security vulnerabilities should follow SECURITY.md.
