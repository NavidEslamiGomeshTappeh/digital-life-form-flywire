# Agent operating rules

This repository is the unified **Version 1.x** product line. Do not create new V-numbered product surfaces.

## Mandatory continuation context

Before substantive work, read **[PROJECT_CONTEXT.md](PROJECT_CONTEXT.md)**. It is the canonical cross-chat/agent research and project-state record.

Scientific rules:
- exact root IDs are mandatory;
- no approximate neuron substitution;
- no invented coordinates, connectivity, morphology, labels, hashes or PASS states;
- source observation, deterministic computation, independent corroboration, biological inference and unresolved claims stay separate;
- external failure remains FAIL or UNAVAILABLE;
- geometry is not a biological compartment label without independent evidence;
- never claim an unpublished historical generator is recovered unless the implementation itself is found and verified.

Engineering rules:
- work against the unified V1 architecture;
- use semantic versions only for real product changes;
- add deterministic tests for substantive implementation changes;
- inspect generated artifacts;
- keep historical research trace in Git history and consolidated evidence rather than adding milestone clutter;
- prefer fail-closed behavior;
- treat provenance and security as product requirements.

Research-positioning rules:
- whole-brain simulation, embodiment, browser demos, and graph analysis already have substantial prior art;
- do not claim absolute novelty;
- the intended differentiator is claim-level, cross-artifact provenance and independent verification;
- a four-neuron/649-row case is a proof case, not the final scope.

Release claims must match evidence.
