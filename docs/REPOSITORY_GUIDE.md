# Repository Guide

The V1 product surface is intentionally small.

src/dlf_flywire/     installable implementation
tests/               canonical tests
data/morphology/     exact reference SWCs
evidence/            consolidated scientific record
docs/                current architecture and scientific record
scripts/             operational validation
.github/             CI, security and research automation

Earlier experimental iterations remain in Git history for audit but are not exposed as separate product versions in the working tree.
