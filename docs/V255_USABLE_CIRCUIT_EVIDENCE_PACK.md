# V255 — Usable Circuit Evidence Pack

V255 turns the V254 reproducible extraction core into a package that a downstream researcher can actually consume.

## Package contents

1. Exact four anchor root identities.
2. Cell-type and related annotations from the pinned flyconnectome/flywire_annotations v3.2.0 release.
3. The exact V229 SWC morphology files, with source hashes and structural validation.
4. The V254-selected directed connections.
5. The 649 exact V230 individual synapse rows.
6. A machine-readable geometry mapping from each anchor-incident synapse to the nearest point on the exact anchor SWC centerline.
7. Source hashes, output hashes, software revision and regeneration commands.
8. A ZIP artifact generated by GitHub Actions.

## Critical semantic boundary

centerline_distance_nm and path_distance_from_soma_or_root_nm are geometric measurements.

They are not evidence that the mapped point is on a biologically annotated dendritic, axonal, synaptic, or electrophysiological compartment. V255 therefore leaves biological_compartment blank and records biological_compartment_status=UNRESOLVED.

This is deliberate: a usable scientific package is more valuable than a convenient but unsupported label.

## Reproduction flow

The GitHub Actions workflow:

1. downloads official Codex FAFB v783 connections;
2. downloads official Codex FAFB v783 individual synapse coordinates;
3. downloads the pinned FlyWire annotation release v3.2.0 at commit a83b2776d60d5764cef36b927f5f9679c16c47a2;
4. rebuilds the V254 core and checks it against V230;
5. validates all four exact V229 morphology files;
6. builds the final package;
7. uploads a ZIP artifact and machine-readable manifests.
