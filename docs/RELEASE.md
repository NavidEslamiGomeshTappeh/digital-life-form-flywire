# Release Contract

Version 1.5.1 is the current unified public baseline.

A release requires:
1. full test suite PASS;
2. canonical repository validation PASS;
3. provenance audit PASS;
4. package build PASS;
5. synchronized version, citation and changelog metadata;
6. no unsupported scientific claim added;
7. no milestone-specific artifact required by the clean build.

Version 1.5.1 adds the bounded Neural → Leader execution boundary on top of the existing Code Hand, policy, checkpoint/recovery, receipt, and verifier stack. These are part of the release contract.

Future work uses semantic versions 1.x.y instead of new V-numbered product trees.
