# Release Contract

Version 1.0.0 is the consolidated public baseline.

A release requires:
1. full test suite PASS;
2. canonical repository validation PASS;
3. package build PASS;
4. synchronized version, citation and changelog metadata;
5. no unsupported scientific claim added;
6. no milestone-specific artifact required by the clean build.

Future work uses semantic versions 1.x.y instead of new V-numbered product trees.
