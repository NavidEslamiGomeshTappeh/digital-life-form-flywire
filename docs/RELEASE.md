# Release Contract

Version 1.7.1 is the current unified public baseline.

A release requires:
1. full test suite PASS;
2. canonical repository validation PASS;
3. provenance audit PASS;
4. package build PASS;
5. synchronized version, citation and changelog metadata;
6. no unsupported scientific claim added;
7. no milestone-specific artifact required by the clean build.

The 1.7.1 baseline includes the bounded Neural → Leader execution boundary introduced in 1.5.1, claim-level evidence tracing introduced in 1.7.0, and the FlyVis continuous-activity semantics guard introduced in 1.7.1. These capabilities are part of the release contract.

Future work uses semantic versions 1.x.y instead of new V-numbered product trees.
