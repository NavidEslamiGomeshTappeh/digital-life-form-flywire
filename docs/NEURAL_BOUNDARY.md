# Neural → Leader Execution Boundary\n\n## Purpose\n\nThis document defines the first executable boundary between a neural signal representation and the existing Leader/Code Hand execution stack.\n\n## Proven chain\n\nThe implemented contract is:\n\n1. NeuralObservation carries an opaque neuron/channel ID, spike count, and bounded time window.\n2. NeuralIntentGateway converts observations into deterministic IntentCandidate records.\n3. Each candidate carries a SHA-256 fingerprint of the complete observation set.\n4. NeuralLeaderBridge converts an activated candidate into the existing TaskStep contract.\n5. TaskOrchestrator remains responsible for dependency ordering, checkpoint/recovery, and execution.\n6. The policy gate remains responsible for permission, network access, and system mutation.\n7. The independent Verifier remains responsible for receipt/state integrity.\n\n## Safety boundary\n\nNeural activity is not trusted with authority.\n\nIt cannot:\n\n- grant its own permission;\n- enable network access;\n- enable system mutation;\n- bypass the policy gate;\n- change the execution destination;\n- bypass receipt verification.\n\nAn inactive candidate or an observation window mismatch fails closed.\n\n## Scientific boundary\n\nThe current integration regression deliberately uses opaque synthetic channel identifiers. It proves the software boundary only.\n\nIt does not prove:\n\n- that T4a/T4c/T5a/T5c currently generate an execution intent;\n- that a biological FlyWire circuit is an action-selection circuit for Code Hand;\n- that camera input is already connected to the FlyWire circuit;\n- that a biological spike stream can be decoded into the configured capability rules.\n\nThose require new evidence and experiments.\n\n## Next engineering stages\n\n### Stage A — real signal adapter\n\nAdd a versioned adapter for a real signal source (recorded spike trains, simulator output, or later camera-derived neural activity). Preserve the raw signal fingerprint and adapter version.\n\n### Stage B — evidence-backed mapping\n\nReplace opaque test channels with a mapping whose neuron/circuit identity and functional interpretation are supported by explicit source evidence.\n\n### Stage C — closed-loop execution\n\nConnect selected intent → Leader → Hand → Verifier → feedback, with every transition recorded as a receipt.\n\n### Stage D — learning\n\nOnly after the deterministic path is stable should adaptive weights, surprise, memory, replay, or reinforcement modify the intent mapping. Learned state must be checkpointed and independently verifiable.\n\n## Non-claim\n\nThis layer is an execution architecture milestone, not a biological discovery claim.\n
