# Accessibility

## Commitment
The project aims to make documentation, reports, machine-readable evidence and GitHub workflows usable by people with different visual, motor and cognitive needs.

## Practices
- Use descriptive headings and plain-language labels.
- Give tables clear headers and do not rely on color alone.
- Provide descriptive captions or alternative text for figures where applicable.
- Prefer machine-readable CSV and JSON evidence.
- Keep commands and expected outputs available as text.

## Known limitations
Interactive GitHub interfaces, third-party scientific viewers and some binary source formats may have accessibility constraints outside the repository's control.

## Reporting barriers
Open an issue describing the affected file or page and a reproducible way to encounter the barrier. Do not include sensitive information.
